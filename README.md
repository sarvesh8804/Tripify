# 🌐 Tripify

**Tripify** is a futuristic travel application that redefines how you explore the world. With advanced **AR (Augmented Reality)** and **VR (Virtual Reality)** integration, Tripify offers immersive travel experiences—from planning your trips to virtually exploring destinations.

---

## ✨ Key Features

- 🔍 **Discover Destinations**  
  Browse curated travel spots, local attractions, restaurants, and cultural highlights.

- 🧭 **Augmented Reality (AR)**  
  Overlay information, guides, and navigation onto your real-world surroundings.

- 🕶️ **Virtual Reality (VR)**  
  Take 360° immersive virtual tours of locations before visiting.

- 🧳 **Itinerary Planner**  
  Build personalized travel plans by adding locations, dates, and notes.

- 📍 **Interactive Maps**  
  Integrated maps with location tagging and live navigation support.

- 📶 **Offline Mode**  
  Save travel data, maps, and VR tours for access without internet.

- 🤝 **Share Your Journey**  
  Share itineraries and experiences with friends or the travel community.

## ⚙️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript, React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB / PostgreSQL
- **AR/VR Libraries:** WebXR, A-Frame, Three.js, AR.js
- **APIs:** Google Maps API, Travel APIs (optional)
- **Deployment:** Netlify / Vercel (frontend), Heroku / Render (backend)

## 🚀 Getting Started

### Prerequisites

- Node.js and npm installed
- Git installed
- A modern browser with WebXR support (for AR/VR)

### Installation

```bash
# Clone the repository
git clone https://github.com/sarvesh8804/Tripify.git
cd Tripify

# Install backend dependencies
cd backend
npm install
npm start

# In another terminal, install frontend dependencies
cd ../frontend
npm install
npm start
```

Open the app in your browser at http://localhost:3000
